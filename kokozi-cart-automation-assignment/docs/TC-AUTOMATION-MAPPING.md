## 자동화 시나리오 확장

원본 TC의 사전조건과 기대 결과까지 자동으로 확인하기 위해 로그인과 회원 전환 절차를 포함했습니다.

| 자동화 단계 | 구현 위치 | 판정 기준 |
| --- | --- | --- |
| 코코지 앱 실행 | `launchApp()` | 앱 홈 신호 확인 |
| 코코지몰 진입 | `waitForNode()` + `tapNode()` | 앱 헤더의 코코지몰 선택 |
| 회원 A 로그인 | `loginMember()` | 이메일·비밀번호 입력 후 회원 화면 확인 |
| 정상 상품 A 선택 | `selectProduct()` | 지정 상품 또는 첫 판매 가능 상품 선택 |
| 구매하기 선택 | `findByScrolling()` | 버튼의 실제 bounds 탭 |
| 필수 옵션 선택 | `selectRequiredOption()` | 옵션 선택 후 담기 버튼 활성화 |
| 장바구니 담기 | `runKokoziMallCartTest()` | 활성화 상태 확인 후 탭 |
| 담기 완료 확인 | `waitForNode()` | 장바구니 이동 버튼 확인 |
| 회원 A 장바구니 검증 | `assertMemberCart()` | 상품명·옵션·가격·수량·이미지 확인 |
| 회원 B로 전환 | `logoutMember()` + `loginMember()` | 회원 B 로그인 후 장바구니 진입 |
| 회원별 데이터 격리 검증 | `assertOtherMemberUnaffected()` | 회원 A 상품이 회원 B 장바구니에 없음 |

## PASS 기준

아래 조건을 모두 만족해야 PASS입니다.

1. Android 앱의 코코지몰 진입 경로를 사용합니다.
2. 회원 A로 로그인합니다.
3. 정상 판매 상품 A와 필수 옵션을 선택합니다.
4. 담기 완료 안내와 장바구니 이동 기능이 동작합니다.
5. 회원 A 장바구니에 선택 상품의 상품명, 옵션, 가격, 수량, 이미지가 표시됩니다.
6. 회원 B 장바구니에는 회원 A가 담은 상품이 표시되지 않습니다.

단순히 장바구니 화면이 열렸다는 이유만으로 PASS 처리하지 않습니다.
